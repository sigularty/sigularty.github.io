Process

How the pipeline works

Each stage reduces the model footprint. Techniques run in fixed order so earlier stages feed cleaner weights to later ones. Your hardware, your data — we never touch it.

01
[cfg]

Configure the pipeline

Enable each technique, tune its hyperparameters, set CQI weights to prioritize what matters — size, latency, or accuracy.

02
[dl ]

Download your file

Every parameter is injected as a literal value into a ready-to-run Colab notebook or Python script. No editing required.

03
[run]

Run on your hardware

Open in Colab (free T4 GPU) or run locally. Load your model and dataloader, then execute. CQI score and report PNG returned.

Installation

pip install Sigularty

One command. No C++ extensions. No custom CUDA build. Pip resolves all dependencies.

bash
pip install Sigularty
# With structured pruning (torch-pruning): pip install "Sigularty[pruning]" # Full install (pruning + ONNX export): pip install "Sigularty[full]"
> colab

Python API

Two functions: compress() and analyze(). The entire public surface.

from Sigularty import compress
result = compress(model, dataloader)
print(result)
# ratio=3.8x | acc=96.4% retained
Reference

API Reference

The complete public API. Two functions. All compression handled internally behind a clean interface.

compress(model, dataloader, *, device=None, model_type='unknown', use_pruning=False, use_lrf=True, use_clustering=True, use_quantization=True, use_kd_finetune=True, use_gptq=False, pruning_ratio=0.3, lrf_epsilon=0.5, num_clusters=16, quant_mode='fp16', cqi_w_accuracy=1.0, cqi_w_size=1.0, cqi_w_latency=1.0, cqi_w_kl=1.0, accuracy_drop_threshold=5.0, ...)
ParameterTypeDefaultDescription
modelnn.ModulerequiredAny PyTorch model. Deep-copied internally — original never mutated.
dataloaderDataLoaderrequiredCalibration / fine-tuning data. Yields (inputs, labels) batches.
devicestrauto'cuda' or 'cpu'. Auto-detected when None.
model_typestr'unknown''classifier', 'embedding', 'generative', or 'unknown'.
use_pruningboolFalseStructured filter pruning. Conv2d layers only.
use_lrfboolTrueLow-Rank Factorization via SVD.
use_clusteringboolTrueWeight clustering (k-means centroid replacement).
use_quantizationboolTrueQuantization (fp16 / dynamic INT8).
use_kd_finetuneboolTrueKD fine-tuning using original as frozen teacher.
use_gptqboolFalseGPTQ INT4/INT8 Hessian-corrected quantization.
pruning_ratiofloat0.3Global fraction of filters to remove (0.05–0.50).
pruning_max_ratiofloat1.0Hard per-layer cap. 1.0 = no cap.
pruning_model_typestr'classifier'Affects behavioral probe thresholds.
pruning_fine_tune_epochsint3Post-pruning fine-tuning epochs.
pruning_fine_tune_lrfloat1e-4Post-pruning fine-tuning learning rate.
pruning_cal_batchesint50Batches for activation importance collection.
pruning_iterative_stepsint1Iterative pruning steps (1 = single-shot).
pruning_isomorphicboolFalseEqual pruning ratio across all layers.
pruning_round_tointNoneRound channel count to 8 or 16 for Tensor Core alignment.
find_optimal_pruningboolTrueAuto-search for best pruning ratio and steps before compressing.
pruning_search_trialsint20Evaluation budget for pruning hyperparameter search.
lrf_epsilonfloat0.5Global rank ratio for SVD. Lower = more compression.
lrf_adaptiveboolFalsePer-layer epsilon from SVD energy analysis.
lrf_energy_thresholdfloat0.99Fraction of singular value energy to retain per layer (adaptive mode only).
lrf_min_layer_sizeint64Skip layers with dim ≤ this. Tiny layers don't benefit.
lrf_min_rankint2Minimum preserved rank. Prevents rank-1 collapse.
lrf_skip_large_kernelsboolFalseSkip Conv2d with kernel >1×1. Required for ResNet/VGG/DenseNet to prevent latency regression.
find_optimal_epsilonboolTrueAuto-search for optimal LRF epsilon before compressing.
epsilon_search_trialsint20Evaluation budget for epsilon search.
num_clustersint16k for weight clustering. 8–256.
cluster_fine_tune_epochsint5Post-clustering fine-tuning epochs.
cluster_fine_tune_lrfloat1e-5Post-clustering fine-tuning learning rate.
kd_epochsint3KD fine-tuning epochs.
kd_lrfloat1e-5KD fine-tuning learning rate.
kd_temperaturefloat4.0Softmax temperature T. Higher = softer teacher distributions.
kd_alphafloat0.7α·CE + (1-α)·T²·KL loss weighting.
quant_modestr'fp16''fp16' (GPU, ~2×), 'dynamic' (INT8 Linear, CPU), or 'static'.
quant_cal_batchesint100Calibration batches for static quantization.
gptq_bitsint44 = INT4 (8× compression), 8 = INT8 (4× compression).
gptq_cal_batchesint16Batches to estimate Hessian from activations.
gptq_block_sizeint128GPTQ column block size. 128 is standard.
cqi_w_accuracyfloat1.0CQI exponent for accuracy factor. Higher = accuracy dominates search.
cqi_w_sizefloat1.0CQI exponent for size compression factor.
cqi_w_latencyfloat1.0CQI exponent for latency speedup factor.
cqi_w_klfloat1.0CQI exponent for KL divergence penalty (pruning search only).
accuracy_drop_thresholdfloat5.0Max allowed accuracy drop (pp) during search. Configs exceeding this are rejected.
num_classesint10Output class count for fine-tuning accuracy metric.
save_reportboolTrueSave compression_report.png after compression.
analyze(model, dataloader=None, *, device=None) → AnalysisResult
ParameterTypeDefaultDescription
modelnn.ModulerequiredAny PyTorch model. Read-only — not modified.
dataloaderDataLoaderNoneOptional calibration data. Analysis uses model weights only if not provided.
devicestrauto'cuda' or 'cpu'. Auto-detected when None.
 
from Sigularty import analyze

analysis = analyze(model)
print(analysis.recommended_techniques)
# ['use_quantization', 'use_clustering', 'use_lrf']

for layer in analysis.per_layer_signals[:5]:
    print(f"{layer.name}: lrf_epsilon={layer.lrf_epsilon:.3f}, prunable={layer.prunable}")
class CompressionResult
AttributeTypeDescription
modelnn.ModuleThe compressed model. Drop-in replacement for the original.
compression_ratiofloatsize_original / size_compressed. E.g. 3.8 = 3.8× smaller.
accuracy_retentionfloat% of original accuracy retained. E.g. 96.4 means compressed achieves 96.4% of original accuracy.
size_original_mbfloatOriginal model disk size in MB.
size_compressed_mbfloatCompressed model disk size in MB.
latency_speedupfloatoriginal_lat / compressed_lat. >1.0 = faster.
techniques_appliedlist[str]Techniques that ran, in pipeline order.
report_pathstrAbsolute path to saved PNG report. None if save_report=False.
pruning_reportdictBehavioral probe results (KL divergence, severity, layers pruned). None if pruning not used.
